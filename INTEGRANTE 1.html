INTEGRANTE 1

Tiempo: 2 minutos
Tema: 1. Análisis del dominio y requerimientos

Guion de exposición

Buenos días. Presentamos el diseño de la base de datos para un Sistema de Gestión de Restaurante. Yo empiezo con el análisis del dominio.

[Mostrar 1.1 Descripción del dominio de aplicación]

El sistema es para un restaurante que atiende clientes y vende alimentos y bebidas. Hoy la información se maneja de forma dispersa: hay datos repetidos, dificultad para saber qué mesas están disponibles y problemas para consultar las ventas y los pagos. Además, cuando la categoría de un producto se escribe en cada pedido, cualquier cambio obliga a corregir muchos registros. Por eso planteamos una base de datos estructurada, con entidades relacionadas, que reduzca la redundancia y facilite la integridad y la consulta.

[Mostrar 1.2 y señalar la tabla de requerimientos de información]

El sistema debe administrar clientes, empleados, mesas, reservas, categorías, productos, pedidos, el detalle de cada pedido y los pagos. De ahí salieron doce requerimientos: registrar y consultar esos datos, y consultar la disponibilidad de mesas, ventas y pagos.

[Señalar la tabla de usuarios y sus necesidades]

Los usuarios son seis: el administrador gestiona empleados, productos, categorías y mesas; el recepcionista registra clientes y reservas; el mozo registra pedidos; el cajero registra pagos; el cocinero consulta los pedidos; y el cliente consulta productos y hace pedidos.

[Señalar la tabla de reglas de negocio]

Las reglas principales: cada cliente se identifica de manera única; una reserva se asocia a un cliente y a una mesa; una mesa puede estar disponible, reservada u ocupada; un pedido lo registra un empleado; y cada producto pertenece a una categoría.

[Señalar la tabla resumen de casos de uso]

Todo esto se resume en diez casos de uso, del CU-01 al CU-10: gestionar clientes, reservas, mesas, productos, categorías y empleados; registrar y consultar pedidos; registrar pagos; y consultar ventas.

Transición al siguiente integrante

Con estos requerimientos y necesidades de información se identificaron las entidades que representan los datos principales del sistema, las cuales serán explicadas a continuación.
